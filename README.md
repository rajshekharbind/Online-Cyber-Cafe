# 🏢 Online Cyber Café Platform

> A production-oriented full-stack platform for managing government job applications, entrance examinations, document services, payments, and cyber café operations.

## 🚀 Overview

The **Online Cyber Café Platform** digitizes traditional cyber café services by connecting **Students/Users, Employees, and Administrators** through a secure and centralized system.

The platform focuses on **security, transparency, application tracking, document management, role-based access control, and operational efficiency**.

# 👥 User Roles

The platform has **three primary roles**:

```text
                    Online Cyber Café
                           │
          ┌────────────────┼────────────────┐
          │                │                │
          ▼                ▼                ▼
      👨‍🎓 STUDENT      👨‍💼 EMPLOYEE      👑 ADMIN
          │                │                │
          ▼                ▼                ▼
     User Services    Application      System Control
                      Processing
```

---

## 👨‍🎓 1. Student / User

The **Student/User** is the customer who uses the platform to discover opportunities and submit applications.

### Responsibilities

* 👤 Manage personal Master Profile
* 📂 Upload and manage documents
* 🔎 Browse jobs and examinations
* ✅ Check eligibility
* 📝 Create applications
* 📊 Track application status
* 💳 Make transparent payments
* 🎫 Create support tickets
* 🧾 View application receipts
* 🔔 Receive application notifications

### Access

```text
Student
 ├── Own Profile
 ├── Own Documents
 ├── Own Applications
 ├── Own Payments
 └── Own Support Tickets
```

> A student can access only their own data and resources.

---

# 👨‍💼 2. Employee

The **Employee** handles day-to-day application processing and customer support.

### Responsibilities

* 📋 View assigned applications
* 🔍 Review application information
* 📂 Verify documents
* 📝 Process application forms
* 🔄 Update application status
* 📅 Monitor deadlines
* ⚡ Handle application priorities
* 🧾 Upload submission receipts
* 🔢 Add registration/application numbers
* 🎫 Handle support tickets
* 👤 Assist students

### Access

```text
Employee
 ├── Assigned Applications
 ├── Application Processing
 ├── Document Verification
 ├── Support Tickets
 ├── Submission Records
 └── Operational Tasks
```

> Employees can access operational data required for their assigned work, but cannot perform administrative system-level operations.

---

# 👑 3. Admin

The **Admin** has the highest level of system control and manages the overall platform.

### Responsibilities

* 👥 Manage users
* 👨‍💼 Manage employees
* 🔐 Manage roles & permissions
* 📋 Manage applications
* 💰 Manage platform/service fees
* 📊 View system analytics
* ⚡ Override application priorities
* 📝 Manage jobs and examinations
* 🎫 Monitor support operations
* 🔎 View audit logs
* ⚙️ Manage system configuration

### Access

```text
Admin
 ├── User Management
 ├── Employee Management
 ├── Role & Permission Management
 ├── Application Management
 ├── Job / Exam Management
 ├── Payment & Pricing Management
 ├── Analytics
 ├── Audit Logs
 └── System Configuration
```

> Admin has system-wide access, while sensitive actions are recorded through the audit logging system.

---

# 🔐 Role-Based Access Control

The platform uses **RBAC (Role-Based Access Control)** to ensure that users can access only the resources permitted by their role.

| Feature              | Student | Employee | Admin |
| -------------------- | :-----: | :------: | :---: |
| Own Profile          |    ✅    |     ❌    |   ✅   |
| Own Documents        |    ✅    |     ❌    |   ✅   |
| Create Application   |    ✅    |     ❌    |   ✅   |
| Process Application  |    ❌    |     ✅    |   ✅   |
| Verify Documents     |    ❌    |     ✅    |   ✅   |
| Support Tickets      |    ✅    |     ✅    |   ✅   |
| Payment              |    ✅    |     ❌    |   ✅   |
| Manage Fees          |    ❌    |     ❌    |   ✅   |
| Manage Employees     |    ❌    |     ❌    |   ✅   |
| Manage Users         |    ❌    |     ❌    |   ✅   |
| Analytics            |    ❌    |  Limited |   ✅   |
| Audit Logs           |    ❌    |  Limited |   ✅   |
| System Configuration |    ❌    |     ❌    |   ✅   |

---

# ⭐ Core Features

### 📂 Document Vault

Securely store and reuse application documents.

### 🧊 Application Snapshot

Creates an immutable copy of profile information when an application is submitted, ensuring historical applications do not change when the master profile is updated.

### ⚡ Deadline-Based Priority

| Deadline     | Priority    |
| ------------ | ----------- |
| `< 24 hours` | 🔴 Critical |
| `< 3 days`   | 🟠 High     |
| `3–7 days`   | 🟡 Medium   |
| `> 7 days`   | 🟢 Normal   |

### 💳 Transparent Billing

```text
Official Application Fee
          +
Platform Service Fee
          =
      Total Amount
```

### 📊 Analytics

Admins can monitor:

* Users
* Applications
* Revenue
* Jobs
* Employee performance

### 🧾 Audit Logging

Sensitive actions are recorded with:

```text
Actor
Action
Resource
Timestamp
Category
```
